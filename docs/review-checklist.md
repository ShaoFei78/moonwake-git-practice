# Pull Request Review Checklist

## 修改范围

- [ ] PR 的修改目标明确
- [ ] 没有混入与任务无关的文件
- [ ] 分支和 Commit 信息符合仓库规范

## 内容质量

- [ ] 修改内容与 PR 描述一致
- [ ] 文档、配置或代码没有明显错误
- [ ] README 或使用说明在需要时已经同步更新

## 验证与安全

- [ ] 作者提供了可以重复的验证方法和实际结果
- [ ] 没有提交构建产物、数据集、模型权重或大体积日志
- [ ] 没有提交密码、Token、私钥或含敏感信息的环境文件

## Review 结论

Reviewer 应选择一种明确结论：

- Comment：仅提供建议，不阻止合并；
- Approve：修改满足要求，可以合并；
- Request changes：存在必须修复的问题，暂时不能合并。
